                         ROLES DROPDOWN LOCATION
================================================================================
WHERE: Tenant Management Page → "Add New Tenant" Side Drawer
FILE: apps/dispatcher-web/src/app/components/tenant-management/
      tenant-management.component.ts (Lines 16-21, 62-67)
      tenant-management.component.html (Lines 54-60)
DROPDOWN OPTIONS:
   1. Tenant Admin (for vendors)
   2. Central Dispatcher (routes to /onboarding/central-dispatcher)
   3. Store Dispatcher (routes to /onboarding/store-dispatcher)
   4. Driver (routes to /onboarding/driver)
DEFAULT: Store Dispatcher
HOW IT WORKS:
   1. Admin selects role from dropdown
   2. Admin sends invitation
   3. Role is encoded in invitation URL as query parameter
   4. When user accepts, role is read from URL
   5. User is routed to role-specific onboarding page
================================================================================
                            USER JOURNEY
================================================================================
1. ADMIN INVITES USER
   Location: /tenants (Tenant Management)
   Action: Click "+ Add New Tenant"
   Step 1: Select role (dropdown shows all 4 roles)
   Step 2: Enter email
   Step 3: Click "+ Invite"
   Result: Invitation sent with role in URL
2. USER RECEIVES INVITATION
   Email: Contains link like:
   /invite/accept?token=ABC123&role=central_dispatcher
3. USER ACTIVATES ACCOUNT
   Location: /invite/accept?token=ABC123&role=central_dispatcher
   Action: Fill name, password, click "Activate account"
   Result: Route determined by role parameter
4. ROLE-BASED REDIRECT
   Driver         → /onboarding/driver
   TenantAdmin    → /onboarding/vendor
   Central Disp   → /onboarding/central-dispatcher
   Store Disp     → /onboarding/store-dispatcher
5. USER FILLS ONBOARDING FORM
   Action: Fill all required fields
   Step 1: Enter personal information
   Step 2: Upload identity document
   Step 3: Click "Apply for Approval"
6. PENDING APPROVAL
   Location: /onboarding/pending
   Status: Wait for admin approval
7. ADMIN REVIEWS & APPROVES
   Location: /tenants (Tenant Management)
   Action: Review pending applications
   Decision: Approve or Reject
8. USER GAINS ACCESS
   Status: Approved
   Result: User can login and access system
